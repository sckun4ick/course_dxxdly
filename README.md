# dYdX Grants — Веб-приложение грантовой платформы

Курсовая работа по дисциплине «Проектирование и разработка веб-приложений».

## Стек технологий
* **Frontend:** React 18, Vite, React Router DOM, SCSS
* **Backend:** Node.js, Express, `pg` (PostgreSQL driver), CORS
* **База данных:** PostgreSQL 18 (реляционная схема из 4 таблиц + `JSONB`)
* **Инфраструктура:** Docker, Docker Compose

## Что понадобится для запуска
* **Docker Desktop** (должен быть запущен перед стартом проекта)
* **Node.js** (версии 18 и выше) и `npm`

## Для Docker 
```bash
docker-compose up -d
```

## Для Backend'a 
```bash
cd backend
npm i
node index.js
```
## Для Frontend'a
```bash
npm install
npm run dev
```
